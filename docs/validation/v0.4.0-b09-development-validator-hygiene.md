## Root cause

The development validator intentionally checks source hygiene first. The canonical release-evidence workflow generated `dist/` and `releases/` package outputs before invoking `npm run validate`, so the workflow invalidated the clean-checkout precondition itself.

The fix does not weaken `validateHygiene`, does not add generated release ZIPs to source control, and does not use destructive cleanup. The release-evidence workflow now captures the development-validator result from the clean source checkout before deterministic packaging starts.
