## Root cause and classification

The historical `dist/halo-learning-magic-hand-v0.3.0.zip` is not a v0.4 runtime dependency. It is a historical/test fixture used by `tests/browser-harness.test.js` to verify legacy ZIP entry measurements and legacy runtime instrumentation. The v0.4 standalone packaging contract intentionally excludes nested ZIP files, so the two tests that dereferenced the developer-checkout path were not standalone-safe.

The repair does **not** add the 11.4 MB historical binary archive to the v0.4 source package. Instead, `tests/helpers/legacy-v030-fixture.js` reconstructs the minimal historical fixture in an OS temporary directory from canonical source inputs already present in the standalone tree:

- `apps/extension/manifest.json`, with only the fixture version projected to `0.3.0`;
- `apps/extension/src/shared/runtime-index-browser.js`;
- `apps/extension/data/lexical-runtime-index.json`.

The temporary fixture is disposed after each test. Production runtime code and the package ZIP exclusion policy are unchanged.
