# Halo Learning v0.5.0 — Local Dogfood Install Guide

> **LOCAL DOGFOOD — NOT PUBLIC v0.5 RELEASE**
>
> `public_release_ready: false`

This milestone is for real-user local dogfooding of Halo Learning's local observation/data path. It is **not** a public v0.5 release and it does not declare v0.6 design complete.

## 1. Prerequisites

- Node.js 22 or newer.
- Chromium / Chrome / Edge capable of loading an unpacked Manifest V3 extension.
- Run all repository commands from the repository root.

Install the locked dependencies:

```bash
npm ci
```

## 2. Run the dogfood gates

Run the focused local-data tests:

```bash
npm run dogfood:test
```

Install Chromium for browser testing if needed:

```bash
npm run browser:install
```

For ordinary local development, the v0.5 browser suite is:

```bash
npm run dogfood:browser
```

The canonical Linux CI evidence runs these browser tests serially under Xvfb with the native `xdotool` shortcut driver so the installed `Alt+Shift+H` command keeps real browser semantics.

## 3. Build the deterministic DOGFOOD ZIP

```bash
npm run dogfood:package
```

Expected artifact:

```text
dist/halo-learning-magic-hand-v0.5.0-dogfood.zip
```

The ZIP contains `DOGFOOD_BUILD.txt` with the same **LOCAL DOGFOOD — NOT PUBLIC v0.5 RELEASE** status and `public_release_ready: false`.

## 4. Load the unpacked extension

For Chrome open:

```text
chrome://extensions
```

For Edge open:

```text
edge://extensions
```

Then:

1. Enable **Developer mode**.
2. Choose **Load unpacked**.
3. Select:

```text
apps/extension/
```

Do not add host permissions. The canonical manifest remains limited to `activeTab`, `contextMenus`, `scripting`, and `storage`.

## 5. Exercise ordinary English and Traditional Chinese pages

On an ordinary English / EN page:

1. Open or select normal learning text.
2. Invoke Halo and choose **Apply**.
3. Confirm annotation tokens render and the page remains reversible.

Repeat on an ordinary Traditional Chinese / `zh-Hant` / 繁體中文 page.

Sensitive pages must continue to fail closed before private extraction or dogfood capture.

## 6. Open the local Data Dashboard

Open the extension popup and choose:

**Data Dashboard · 本機資料**

The dashboard should expose these local-only views:

- Overview
- Activity
- Sites & Sessions
- Learning Events
- Saved Sentences
- Dogfood Notes
- Data & Privacy
- System / Replay

Overview is descriptive observation only. It must not claim learner mastery, confidence, or level.

## 7. Exercise explicit retention

On an allowed annotated sentence:

1. Open a token explicitly.
2. Choose **Save Sentence · 儲存句子**.
3. Choose **Dogfood Note · 體驗註記**, enter a short note, and save it.
4. Return to the Data Dashboard and confirm the Saved Sentence and Dogfood Note are present.

Passive exposure should remain privacy-minimized; retained sentence text/full return URL is permitted only through the explicit-learning paths defined by the v0.5 capture policy.

## 8. Restart and verify persistence

Close the browser completely, then restart / 重新啟動 it with the same browser profile and unpacked extension.

Reopen the Data Dashboard and verify that:

- English and `zh-Hant` observations remain available.
- the Saved Sentence remains available;
- the Dogfood Note remains available;
- System / Replay still produces a deterministic replay report over the persisted event stream.

The canonical acceptance gate performs a full Chromium close/reopen against the same `userDataDir`, not merely a dashboard-page reload.

## 9. Export before delete

**Always export before delete** when the local dogfood history is useful for later analysis.

Use Data & Privacy to create either:

- JSON export, or
- JSONL event export.

After the export is saved locally, scoped deletion may be exercised by site, date range, or all dogfood data. Delete operations are local to the browser profile and require an explicit confirmation in the dashboard.

## 10. Storage-degraded behavior

If IndexedDB becomes unavailable, Halo's local dogfood status may enter `storage-degraded`. This is observation failure only:

- semantic marking must continue to work;
- Remove/reversibility must continue to work;
- no remote fallback may be introduced;
- the dogfood failure must not become a dependency of the v0.4 semantic/renderer path.
